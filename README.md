# NekoBox 2.0 For PC

NekoBox 2.0 is a massive update based on the original NekoBox.
Qt based cross-platform GUI proxy configuration manager (backend: sing-box)

Support Windows out of the box now.

NekoBox 2.0 是基于原版 NekoBox 的重大更新版本。
基于 Qt 的跨平台代理配置管理器 (后端 sing-box)

目前支持 Windows 开箱即用

## What's New in 2.0 / 2.0 新功能

- **Global Ping Test:** Auto-check schedules, multi-server testing support.
- **One-Click AdBlock:** AdGuard DNS routing integrated at the sing-box core level.
- **Native Tor Mode:** Seamless Tor routing for system proxy and TUN mode.
- **Interactive Traffic Dashboard:** Live animated upload/download speed graph.
- **Updated Design:** Fresh new 3D app icon and UI polish.
